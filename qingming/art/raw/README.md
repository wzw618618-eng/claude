# 美术原图放这里

ChatGPT 画好的图，从 ChatGPT 下载原图（PNG），**原样**传到这个文件夹就行：不用改名、不用压缩、不用裁。
在 GitHub 网页上进到这个文件夹，点「Add file → Upload files」，把图拖进去，提交。

传完告诉 Claude，Claude 会逐张看、裁出头像、压缩、接进游戏。要画哪些图、画成什么样，见 [`../../docs/美术需求.md`](../../docs/美术需求.md)。

方便的话可以把文件名改成图的编号（比如 `shen.png`、`qinglan.png`、`birth_stone.png`、`ending_age.png`），不改也没关系。

# 青冥录：美术与界面交付

完成 31 张基础美术：12 位原始角色、6 位新人、7 个地点、开局、3 种结局、2 件剧情宝物。另生成 18 张头像，共 49 个 WebP 资源，约 3.6 MB。原图使用内置 image_gen 生成，保存在 art/raw；提示词见 art/prompts.json，设计依据为 docs/美术需求.md。原需求中的 24 张可选表情扩展未包含在本次基础资源集。

接入开局、此地、舆图、人物列表与详情、对话、坊市、行囊和结局。新人按门派与性别获得头像，故人立绘褪色，交情由文字与边框表达。调整手机排版、纸墨配色、触控按钮、深色模式与减少动画设置。

## 运行

- npm run preview:build：生成可直接打开的 visual-preview/index.html，使用正式界面控制器及世界会话，支持离线玩法与本地存档。
- npm run build：正式天工引擎构建。
- npm run art：从 art/raw 裁头像、压缩 WebP 并生成 assets/ui/art-data.ts。
- npx tsc --noEmit 与 npx vitest run：类型检查与测试。

图片通过打包数据 URL 接入，避免引擎资源根路径或本地预览造成坏图。代价是启动需加载约 4.8 MB 图片编码数据；大量新增表情时可改为分包加载。

## 验证

- 类型检查通过，60 项测试全部通过。
- 正式引擎构建成功；仍有上游大包和 Rapier wasm 路径警告。
- 浏览器 78 组检查通过：13 种页面、360/390/1280 三种宽度、明暗主题，无横向溢出、坏图或脚本错误。
- 实际试玩开局、柳溪村移动、修炼、花婆婆对话、刷新后存档恢复通过。
- 未使用真实 API 密钥进行付费 AI 请求测试。

Windows 安装：引擎包包含 macOS 的 fsevents，普通 npm install 会失败。本机用 npm install --force --ignore-scripts 完成验证。

本次在 codex/qingming-art-ui 分支开发，不合并现有 PR #1。

## 实时动效

存活角色详情立绘加入轻微呼吸；场景加入缓慢镜头移动和薄雾，集市与赤霄使用暖色流光，洞府与矿脉使用冷色灵光。标题背景缓慢移动，按钮增加按压反馈，保留抽屉过渡。亡故角色不播放呼吸，死亡结局插画保持静止。

动效用于正式游戏和单文件试玩，无新增动画图片下载。使用 transform/opacity、可视区域暂停、后台暂停；遵循系统“减少动态效果”。共用动画时间基准，避免 AI 流式更新使动效反复从头播放。

本版是原画的轻量氛围动画，不包含逐帧眨眼、独立衣袖骨骼动画或真实水面变形；这些需要拆层或补绘专用素材。

## 一、这是什么游戏

《青冥录》是一款原创的修仙题材手机游戏（竖屏）。青冥州有七个地方、十二个有名有姓的修士，各有性格、目标和秘密，玩家和他们打交道、结缘结仇。

界面是「水墨古籍」风：宣纸色的底、黑墨字、毛笔字标题，人物身份用朱砂印章标记。你要画的是放进这个界面里的图：人物立绘、地点场景、开局图、身世图、结局图。

## 二、要多好看

**美术是这个游戏能不能玩下去的关键。** 玩家每天对着这些人说话，人物不好看、不动人，再好的故事也没人看。所以：

- **每一张都要能单独拿出来当手机壁纸**，发到网上让人想收藏。达不到就重画，宁可多画几遍，不要将就。
- 水准参照：中国古代名画的笔墨和意境，加上当代顶级国风美术设定集的完成度。
- **人物要好看**：女子清丽、有韵味；男子俊朗，或者有气势；老人有风骨。不要千篇一律的网红脸，十二个人的脸型、眼型、眉形要各不相同。

好看靠这几样：

| 要点 | 什么意思 |
| --- | --- |
| 有气韵 | 人是活的。衣袂、发丝、发带被风带起，身体有动势，不是站桩 |
| 有戏 | 每个人画的是一个能看出性子的瞬间：一个动作、一个眼神 |
| 墨有层次 | 焦、浓、重、淡、清，五种墨色都要有；不要一片平灰 |
| 有对比 | 浓淡、疏密、虚实对比强烈；大片留白里放一处重色点睛（比如一点朱砂、一抹石青） |
| 精致 | 近看经得起看：衣纹走向、衣料纹样、发丝、配饰、兵器都画得讲究 |
| 远看认得出 | 缩小以后轮廓（发型、帽子、体型、标志物）一眼能分清是谁 |

## 三、画风

### 第零步：风格三选一

正式开画前，先用沈清禾（见第五节）按下面三个方向各画一张，让用户挑一个。挑中的方向就是全套的画风，后面不再换。

| 方向 | 说明 |
| --- | --- |
| **甲：兼工带写**（推荐） | 脸、手、配饰用工笔细细地画，五官精致；衣服、头发、背景用写意的大笔泼墨、飞白。精致和气势都有，最适合做游戏立绘 |
| 乙：工笔淡彩 | 线条精细匀净，设色清雅，像宋代院体人物画和明代仇英的仕女。最精致，最古雅 |
| 丙：水墨写意 | 大笔泼墨、简练飘逸，像梁楷的泼墨仙人。最有意境，但细节少 |

### 统一画风段

**画每一张图时，都把下面这段放进提示词里**（下面是方向甲的写法；用户挑了乙或丙，就把第一句换成那个方向的说明）：

> 中国传统水墨画风，兼工带写：脸、手和配饰用工笔精细勾勒，五官精致传神；衣服、头发和背景用写意的大笔泼墨、飞白和晕染，笔墨酣畅、有气势。墨分五色，浓淡层次丰富；设色雅致，以石青、石绿、赭石为主，一处朱砂点睛。大面积留白，纯白底，画面边缘自然晕开、淡出成白色，不加边框。精致到能收进美术设定集，每一张都能单独当壁纸。没有任何文字、印章、落款、题诗。原创风格，不模仿任何现有游戏或在世画家。

### 用色

用国画颜料的说法，和界面的配色呼应：

| 颜色 | 用在 |
| --- | --- |
| 墨（焦、浓、重、淡、清） | 一切的骨架 |
| 石青、花青 | 青岚宗、天、水、冷意 |
| 石绿 | 草木、灵气、青绿山水 |
| 赭石 | 山石、皮肤、赤霄门的底色 |
| 朱砂、胭脂 | 赤霄门、火、血、点睛的那一处重色 |
| 藤黄、泥金 | 灯火、宝物、灵石、商人的首饰 |
| 蛤粉白 | 雪、云、鹤、梅花、白鹿 |

整体雅致、不艳，但**不要灰扑扑**：每张图里要有一处颜色是饱满的。

### 线条

线条是这套画的灵魂，按人物性子挑描法：

- 清冷、柔美的人（沈清禾、苏小棠、柳如烟）：高古游丝描、兰叶描，细而有弹性
- 刚猛的人（厉擎、秦焰、阿蛮）：钉头鼠尾描、折芦描，起笔重、转折硬
- 老人和散修（温玄、花婆婆、白鹿、墨九、韩烈）：枯笔、战笔，带一点飞白

### 不要

- 日系动漫的大眼睛、尖下巴、二次元脸
- 写实照片感、3D 渲染、厚涂 CG 的高光、发光特效、粒子光效（光要用留白和晕染来表现）
- 画面里出现任何字，包括招牌、旗子、匾额、书信、石碑上的字（要有就留空，或画成花纹、看不清的墨痕）
- 红色印章、签名、水印
- 彩色背景、纸张纹理、渐变底色（底一律纯白，游戏会自己加纸纹）
- 一张图里画好几个版本，或者拼图

## 四、怎么做

### 顺序

| 步 | 画什么 | 张数 |
| --- | --- | --- |
| 0 | 风格三选一：沈清禾按甲、乙、丙各一张，用户挑一个 | 3 |
| 1 | **试稿**：沈清禾（定稿）→ 厉擎 → 青岚宗。画完先停，等用户确认 | 3 |
| 2 | 剩下的十个人 | 10 |
| 3 | 剩下的六个地方 | 6 |
| 4 | 开局图、身世图（测灵石）、三张结局图 | 5 |
| 5 | 后来的新人 | 6 |
| 6 | 选做：表情、宝物 | 26 |

试稿挑沈清禾和厉擎，是因为两人一个清冷纤细、一个魁梧粗犷，一个石青、一个赭红，放在一起最容易看出风格统不统一。

每次只画一张，用户说「下一张」再画下一张。用户说哪张不行，就只重画那一张。

### 写提示词

你给生图写的提示词要具体，至少写到这几样：统一画风段 → 画的是谁或哪里 → 脸和神情 → 姿势和动作 → 服饰和配饰的细节 → 光线和氛围 → 构图（头的位置、留白在哪）→ 用什么描法 → 不要什么。不要只写一句「画一个修仙女子」。

### 保持统一

- 沈清禾定稿以后，就是全套的**风格样板**；青岚宗定稿以后，就是场景的样板。之后每一张的线条粗细、墨色浓淡、上色方式、脸的画法、头身比例都照着样板来，看起来要像同一个画师画的一套。
- 尽量在同一个对话里画完。要是开了新对话，先把沈清禾和青岚宗两张定稿图重新上传，说明「照这两张的画风」。

### 每张画完先自己检查

给用户看之前，先自己对一遍，有一条不过就直接重画：

- [ ] **手**：每只手五根手指（墨九的左手除外），关节和长短自然，没有多出来或粘在一起的手指。没把握就让手藏进袖子，或握住道具
- [ ] **脸**：五官端正，左右眼对得上，眼神有神；和别的角色长得不一样
- [ ] **衣襟**：交领右衽——左边的衣襟压在右边上面，领口在胸前交叉成「y」字形。不能画反
- [ ] **道具**：剑、枪、刀、弓的结构对（弓有弦、枪有枪头和红缨、剑鞘和剑柄连得上），没有穿模
- [ ] **没有字**：画面任何地方都没有文字、假汉字、印章、签名
- [ ] **构图**：符合本节下面的尺寸和构图规范
- [ ] **画风**：和样板放在一起，像同一套
- [ ] **好看**：放到手机壁纸上，你自己愿意用吗？不愿意就重画

## 五、人物立绘

### 规范

- **尺寸**：1024×1536 竖图。
- **构图**：半身像，从头顶画到腰。人物在画面正中，正面或四分之三侧面。
- **头的位置（重要，游戏要从这里裁头像）**：头顶离画面上边大约 1/10；脸的中心在画面高度大约 1/4 处，左右居中。脸周围的底要干净，脸不要被手、帽檐、头发、道具挡住。
- 腰以下用泼墨、飞白晕开，淡出到白，不要硬切。
- 只画这一个人（白鹿可以带上他的鹿）。人物身后可以有一大笔淡墨晕染或几点墨渍衬托，但不要画成完整的背景景物。
- 手机上最小只显示一张脸（约 40×40 像素），所以轮廓和五官要清楚；近看时细节要丰富。
- **只画对外公开的样子，不要画出他们的秘密。**
- 修仙的人老得慢：按下面写的「看上去多大」画，不是按真实年龄。

### 门派服饰

- **青岚宗**（正道大宗，山门在云雾里）：月白色的宽袖长袍，衣领、袖口镶石青色的边，衣角和袖口有淡淡的云纹暗绣，腰系素色丝绦。整洁、端正、飘逸。
- **赤霄门**（强者为尊，天天比斗）：赭红配玄黑的劲装，窄袖、皮护腕、宽束腰，衣边有火焰纹。利落、粗犷。
- **散修**：各穿各的，见每个人的描述。

- 一眼认出：斗笠、黑衣、缺两根手指的左手、脸上的疤。

## 六、地点场景（7 张）

### 规范

- **尺寸**：1536×1024 横图。
- **构图**：要有近景、中景、远景三层（三远法），有纵深。要紧的东西放在画面中间那一横条里，上下各大约 1/5 可能会被裁掉。四周晕开、淡出成白色，好融进纸色的界面。
- 可以有很小的人影点缀，让画面有生气，但不要能看清脸的人物（人物都在立绘里）。
- 招牌、旗子、匾额、石碑上不要写字。
- 每处有自己的时辰、天气和主色，七张放在一起要各不相同。

### 七个地方

**1. 青岚宗（qinglan）——场景样板，试稿第三张**
正道大宗，山门藏在云雾里。青绿山水，参照王希孟《千里江山图》的石青石绿，但更空灵、留白更多。
清晨，云海翻涌，几座陡峭的主峰从云里拔起；峰腰和峰顶有白墙青瓦的殿阁、飞檐翘角；一道长长的石阶穿过苍松，蜿蜒上山，石阶上一两个极小的人影；三两只白鹤从峰间飞过。近景是一角山石和斜伸出来的松枝。晨光从云后透出来，用留白表现。
感觉：仙气、清正、高远。

**2. 赤霄门（chixiao）**
强者为尊，门里天天有人比斗。参照范宽《溪山行旅图》那种压人的山体，用赭石和朱砂染。
夕照，巨大的赭红色山崖压在画面上方；崖下是石砌的大殿，粗犷厚重；殿前一座圆形石台，台上两个极小的人影正在交手；台边火盆烧着，几面没有字的红旗被风扯得笔直。
感觉：硬、热、有力量。

**3. 云渡坊（market）**
买卖丹药法宝的坊市，消息最灵通。参照张择端《清明上河图》的市井气，只取一段。
傍晚灯刚上，一条河从画面中间横过；岸边木楼鳞次栉比，檐下挂满暖黄的灯笼，倒影落在水里；一座拱桥，河上渡船和小舟；码头上许多极小的人影在搬货、交易；远处雾里是淡淡的山。
感觉：热闹、有烟火气，又有点神秘（什么都能买到）。

**4. 听泉谷（vein）**
一条灵脉从谷底流过。参照马远、夏圭的「边角之景」，大片留白。
早春雪后，山谷一角：一道细瀑布落进清潭，溪水里流着一缕若有若无的石绿（灵脉，要含蓄，不要发光特效）；溪边几株老梅，开着红白梅花；一间茅屋；屋前一头白鹿低头饮水。
感觉：静、清、远离人世。

**5. 玄冥洞府（cave）**
上古修士留下的洞府，机缘多，埋的骨头也多。焦墨、浓墨为主。
夜。黑色陡崖占满画面，崖壁上一个深不见底的洞口；一扇巨大的古石门半开着，门上刻着模糊的上古纹样（没有字）；门缝里透出一点幽青的冷光（用淡石青晕染，不要特效）；门前散落着白骨和一柄断剑；寒雾从洞里流出来，漫过画面下方。
感觉：阴森、诱人、藏着秘密。

**6. 黑松林（forest）**
妖兽出没，历练的好去处。
月夜起雾。扭曲的老松张牙舞爪，层层叠叠往深处去，越深越黑；林子深处有一双发亮的兽眼，和一个巨大兽影的轮廓（藏在雾里，看不全）。近景一条小路走进林子。
感觉：危险、压迫，但让人忍不住想进去。

**7. 柳溪村（village）**
山脚下的凡人村子。文人画里的田园小景。
春日午后。一条小溪绕村而过，岸边垂柳新绿；几户茅草顶的农舍，炊烟袅袅；田埂上有牛和极小的农人；一座小木桥；远处是青山，山顶隐约能看见宗门的殿阁。
感觉：平和、温暖、人间。

## 七、开局图、身世图和结局图（5 张）

人物都只是很小的背影或剪影，不画脸（身世图只画一只手）。这几张是玩家最先看到和最后看到的，**要最有意境**。

**开局图（title）**：1024×1536 竖图，游戏打开看到的第一张。参照郭熙《早春图》那种竖幅的层叠山水。
**上面三分之一留空**，只有淡淡的天光和云气（游戏会在这里写「青冥录」三个大字）。下面是层层叠叠的山峦和云海，从近到远越来越淡；一条山路蜿蜒进山；路上一个很小的背影，背着包袱和剑，看不出男女（这是玩家）；一只白鹤从他头顶飞向远山。
感觉：辽阔、安静，有一点孤独，又让人想走进去。

**身世图（birth_stone）**：1024×1024 方图。开新局时，玩家先读一段自己的身世，然后「把手按上测灵石」——灵根是好是坏，就看石头里亮起几道光。这张图就画手按上去之前的那一刻。
- 画面正中是一块测灵石：半人高、上圆下方的一整块青灰色玉石，立在一个朴素的石座上。**石面要温润、光滑、颜色均匀，不画花纹、裂纹、光点和发光**——游戏会在石面中间叠上五行的光（金白、木青、水蓝、火赤、土黄，一到五道，是随机的），所以石头本身必须是「还没亮」的样子。
- **石面的中心正好在画面的正中**（左右、上下都居中），石头大约占画面宽度的一半。
- 一只年轻人的手从画面右下方伸进来，五指张开，掌心离石面只差一寸，还没碰到。只画手和一截粗布袖口，看不出男女（玩家可能是男是女）；手要画得好：五根手指，关节自然，指尖有一点紧张。
- 四周淡墨晕开、淡出成白色，不画具体地点（玩家的出身有六种：村口、药婆婆的屋里、坊市铺子、赤霄门、青岚宗山门……这张图要哪里都说得通）。
- 光线：清冷的晨光从左上方来，用留白表现；石头上有一点含蓄的玉的光泽，不要高光和特效。
- 感觉：屏住呼吸，命运揭晓的前一刻。

**结局图**：1536×1024 横图，各一张。

| 编号 | 结局 | 画什么 | 感觉 |
| --- | --- | --- | --- |
| ending_age | 坐化（寿元耗尽） | 黄昏，山崖上一棵老松，树下一个人盘腿静坐的背影，面向远方的落日和云海，松针和落叶慢慢飘下 | 平静、圆满、一点怅然 |
| ending_dead | 陨落（死于非命） | 荒原上斜插着一柄剑，剑穗被风吹起；地上残雪和零落的梅花，远处一抹残阳，一只孤鸦 | 萧瑟、遗憾 |
| ending_ascend | 化神（破境飞升） | 一个人影踏云而上，衣袂翻飞；下面是渺小的青冥州山川；上方云层裂开，透下大片的光（用留白和淡墨表现，不要特效）；几只白鹤随行 | 壮阔、超脱 |

## 交付和验收（给用户看）

**怎么交**
- 从 ChatGPT 下载原图（PNG）。不用改文件名、不用压缩、不用裁。
- 交给 Claude：在对话里直接发图，或者传到仓库的 `qingming/art/raw/` 文件夹（在 GitHub 网页上进这个文件夹，点「Add file → Upload files」就能传）。

**觉得不好看时，怎么跟 ChatGPT 说**
别只说「不好看」，说具体哪里，它才改得对：

| 毛病 | 这样说 |
| --- | --- |
| 太灰、太平、没精神 | 「墨色拉开层次，浓的地方更浓，加一处饱满的重色点睛」 |
| 人像木头、站桩 | 「让他动起来：身体有动势，衣袂和头发被风吹起」 |
| 脸不好看、和别人长一样 | 「按文档写的脸型和眼型重画脸，要更精致、更有辨识度」 |
| 太像 AI 图、太油太亮 | 「去掉高光和光效，用毛笔笔触和留白，像真的画在纸上」 |
| 太简单、太空 | 「衣纹、纹样、配饰、发丝画得更精细」 |
| 太满、太乱 | 「留白再多一些，只保留主体」 |
| 和前面的画风不一样 | 「照沈清禾那张定稿的画风重画：线条、上色、脸的画法都一样」 |

**Claude 那边会做**
- 每张图逐张看：手、衣襟、画风统不统一、放在游戏里好不好看。不行的会写好让 ChatGPT 重画的话，你转过去就行。
- 从立绘里裁出头像，压缩成适合手机的大小，处理深色模式，已故的人自动褪色，再把图接进游戏、在手机尺寸下检查。
- 图标、印章、舆图、纸纹这些小东西 Claude 用代码画，不用 ChatGPT 画。

# 青冥录（制作中）

一款原创的修仙沙盒：一个州、七个地方、十二个有名有姓的修士，一局几十到上百年。重点是**角色自己有脑子**——他们有性格、看重的东西、长远的目标和秘密，每年自己拿主意、彼此结缘结仇，记得你对他们做过什么，还会把听来的事传出去。

> 第 1 阶段（世界和 NPC 的心）已完成，还没有界面。接天工引擎、界面、美术在后面几个阶段。

## 角色的「心」

| 部分 | 在哪 | 做什么 |
| --- | --- | --- |
| 性格、价值 | `assets/game/data/people.ts` | 傲慢、谨慎、阴狠、痴情……五项价值：力量、财富、情义、忠诚、正义 |
| 长远目标 | `assets/game/mind/goals.ts` | 报仇、争宗主、寻师、求道侣、夺宝、求长生、拜入宗门，每种三四步，按年推进；秘密目标对外有一套说法 |
| 记忆和传闻 | `assets/game/mind/memory.ts` | 亲历算满分，目睹算一半，听说再减半；见面时把印象深的事讲给别人听 |
| 每年的打算 | `assets/game/systems/year.ts` | 有目标为目标奔走，没有就按性子挑事；同一处的人论道、冲突、闲聊；老去、选宗主、生出新念头、新人到来 |
| 找上门的事 | `assets/game/player.ts` | 寻仇、约你入伙、拉你一起动手、翻脸、表白、收徒、透露秘密、比斗 |

十二个人的目标和秘密是咬合的：温玄当年害了师兄云鹤、灭了墨家；沈清禾在找师父；墨九要报灭门之仇；陆沉舟想夺宗主之位，也是杀秦焰哥哥的人；苏小棠喜欢陆沉舟；白鹿暗恋沈清禾；厉擎和柳如烟都盯着洞府里的玄冥剑；韩烈想篡位；阿蛮想拜入宗门；花婆婆什么都知道一点。你知道的秘密可以告诉别人，会改变他们的打算。

# 青冥录（制作中）

一款原创的修仙沙盒：一个州、七个地方、十二个有名有姓的修士，一局几十到上百年。重点是**角色自己有脑子**——他们有性格、看重的东西、长远的目标和秘密，每年自己拿主意、彼此结缘结仇，记得你对他们做过什么，还会把听来的事传出去。

> 第 1 阶段（世界和 NPC 的心）、第 2 阶段（接天工引擎）、灵魂层（DeepSeek V4.1 Flash，交情越深越有灵性）、第 3 阶段（正式界面）、第 4 阶段（玩法完善：修 bug、节奏和平衡、各地的事、出身、新手引导、声音）、第 5 阶段（站在玩家这边抠细节：灵根出身天定、离线也会说话、不该看到的看不到）已完成。美术（人物画、场景）还没做，需求写在 [docs/美术需求.md](docs/美术需求.md)。

## 站在玩家这边（第 5 阶段）

一边当玩家玩，一边把出戏、不讲理、看不懂的地方一处处抠掉。

### 开局：灵根和出身由天定

开局只起道号、选性别。灵根和出身是投出来的（`world.ts` 的 `rollBirth`，同一个种子投出来一样，不能重投），进游戏先看一段身世：你是谁、在哪摸的测灵石、石中亮起几道光、旁边的人怎么说（花婆婆、仙师、执事各说各的；坊市账房是夜里一个人偷偷摸的）。

| 灵根 | 多少 | 长处（只管天生的资质） |
| --- | --- | --- |
| 天灵根（一种五行） | 12% | 修炼最快；悟性好：听泉悟道、请教前辈所得更多 |
| 双灵根（两种） | 38% | 福缘深：在外多遇好事，历练所得多三成 |
| 杂灵根（三到五种） | 50% | 修炼慢些；根基稳：冲关失败只跌两成修为；药力吸收得足：破境丹 +30%、回春丹回七成、延寿丹每次多 10 年 |

灵石、丹药这些家底改成看出身（以前杂灵根「每年家里捎来灵石」，投到墨家遗孤就说不通了）：人人 30 块灵石，山野无名多 40，坊市账房多 130，药婆婆家的孩子带两颗回春丹，其余多 10。

| 出身 | 多少 | 和谁绑在一起 | 第一次碰上时 |
| --- | --- | --- | --- |
| 山野无名 | 26% | 谁也不认得，多些碎灵石 | — |
| 墨家遗孤 | 12% | 墨九认你、知道他的打算；温玄起疑 | 墨九认出你，告诉你灭门的是温玄；可以答应一起报仇 |
| 药婆婆家的孩子 | 16% | 花婆婆是亲人，阿蛮是玩伴；懂草药 | 花婆婆塞给你一颗攒了多年的破境丹 |
| 坊市账房出身 | 16% | 从云渡坊出发；柳如烟认得你，韩烈欠你东家的钱；卖东西多两成 | 柳如烟送你回春丹；可以找韩烈讨债（打得过他才肯还） |
| 赤霄门弃徒 | 14% | 炼气中期起步；秦焰是旧识，厉擎、韩烈不待见你 | 秦焰谢你当年替他出头 |
| 青岚外门杂役 | 16% | 从青岚宗山门出发；沈清禾、苏小棠和你熟，陆沉舟当你是棋子 | 沈清禾答应拜山那天替你说话（把握 +20%） |

这几场戏在 `systems/meet.ts`，要真的和那人在同一处才演，每人只演一次。

### 离线也会说话

没接 AI 时，以前十二个人对你说的话几乎都是「嗯。」。现在每人有一套自己的说法（`data/voices.ts`）：怎么称呼你（花婆婆叫「娃儿」、陆沉舟叫「师弟」、厉擎叫「小子」、阿蛮叫「哥」），看你顺不顺眼时怎么打招呼，问修行怎么答，问往事怎么岔开，道谢、被夸、告辞各怎么说。

自由对话会听你说的是什么（`ai/lines.ts`）：问修行、问某人（「婆婆去哪了」会告诉你她今年在哪）、问地方、问玄冥剑在谁手里、问他今年在忙什么、问他往后的打算、问往事、要拜师、切磋、买丹药、表白、道谢、夸、骂、告辞、问他是谁。能透露的秘密、能顺势提出的事（指点、收徒、切磋、卖丹药、结为道侣、请你帮忙）和 AI 一样受规则门槛约束，离线时也会提，绝不多说。同一句话不会紧挨着说两遍。

「打听消息」先说他亲历亲见的大事，再说这几年江湖上的大新闻，同一件事不说两遍；闲聊（谁和谁聊得投机）不算消息。瞒着人的打算，对外的说法写成完整的一句话。

### 不该看到的看不到

- 为瞒着人的目标奔走时，人物列表里只看得到他在修炼、闭关、办事，或者「不知在忙些什么」（以前会直接写「去找温玄算账」「寿元不多了，只能硬冲一把」）；打听出他的打算以后才看得到。
- 别人私下查到的秘密，江湖上只传个影子（「秦焰四处打听了好些年的旧事，这些天忽然不再打听了」）；你本来就知道才写明。当众说出来的事，你也算知道了。
- 离线时人物页不再讲「灵魂」「聚光 / 在场 / 离场」「AI 回答」这些说法；接上 AI 才讲交情深了他会多做哪些事。

### 其他抠掉的细节

- 第一年每个人就有打算（以前第一年谁都没有打算，都待在家里）。
- 同一个人比斗过、被你回绝过拜师和收徒、求你帮忙被拒，几年内不会年年来找你。
- 选项对话注定不成的，按钮灰掉并写明原因（好感不够、信任不够、不收徒、徒弟收满了……），碰运气的写上把握（切磋、引荐入门）。
- 早就认得你的人（出身里的旧识、见过面的、交情深的），找上门时不再「打量了你很久：你的根骨不错」。
- 来寻仇的人会说出为了什么（「你揭穿了我——今天就是你的死期」）；逃跑写上把握。
- 闭关几年后说清楚修到了哪一步、是不是被人找上门打断了。
- 修为没圆满时不再摆出灰掉的「服丹冲关」；新手引导指着的地方会滚到看得见的位置；「交情」提示不再打断第一年的引导；文案里的他 / 她按性别写；结局的修行年数按年纪算。

平衡（`npm run sim:qm`，出身和真玩一样随机）：精打细算的玩家化神率 天 / 双 / 杂 = 91% / 83% / 81%，随手玩 53% / 35% / 20%。天灵根少见，投到了是运气。

行为测试 88 个（新加的 11 个在 `__tests__/player.test.ts`）。

## 玩法完善（第 4 阶段）

### 开局

开局的灵根和出身见上面第 5 阶段（现在由天定）。AI 演的人如果和你的出身有牵连，提示词里会写上你的来历；你的名分（宗主、弟子、散修）和名声也会写进去。

### 每年的主事

| 主事 | 什么时候有 | 做什么 |
| --- | --- | --- |
| 修炼 | 一直 | 长修为 |
| 闭关冲关 / 服丹冲关 | 修为圆满 | 冲下一个大境界；破境丹自己选用不用。失败受伤、跌修为，但每败一次下次把握大一些 |
| 布阵修炼 | 一直 | 花灵石（按境界 15～240），修为多两成半 |
| 各地专属的事 | 看地方 | 青岚宗藏经阁参悟（花功劳）、赤霄门上擂台、拜山（非门人）、云渡坊茶楼打听（先打听谁在找你）、听泉谷悟道（下次冲关把握 +15%，天灵根 +22%，白鹿在场再 +5%）、玄冥洞府闯深处（遗书、玄冥剑）或寻灵药、黑松林采药、柳溪村行医施药 |
| 历练、做事 | 一直 | 和这里的妖兽打一场（越凶险的地方越凶）；挣灵石、攒功劳或名声 |
| 当众揭发温玄 | 带着云鹤遗书在青岚宗 | 沈清禾或花婆婆在场就没人不信：温玄被逐，沈清禾转而报仇，墨九的仇有了凭据；没人作证就看你的名声和人缘 |
| 开辟洞府 | 金丹，听泉谷、黑松林、柳溪村、玄冥洞府 | 200 灵石；以后在那里修炼更快、不出意外 |
| 传功 | 金丹，有徒弟在场 | 徒弟和你都长修为 |
| 开坛讲道 | 元婴，在场至少两人 | 人人有所得，名声 +6，仰慕你的人当场拜师 |
| 镇守此地 | 元婴，柳溪村、云渡坊、黑松林、听泉谷 | 每年有供奉和名声；有魔修来犯会有人报信，得赶回去 |
| 主持宗务 | 你是宗主（门主），人在山上 | 供奉 60 灵石，门人更服你 |

打交道多了几样：金丹以后**收为弟子**（徒弟数随境界涨，当宗主再多两个）；当了宗主能**收入门下**、**逐出门墙**。名声到了，还会有人慕名找上门来拜师。

### 途中碰上的事

到了一个地方，按那里的凶险程度碰上意外（太平的青岚宗很少，玄冥洞府三成多）。17 种：灵芝、狼群、受伤的散修（救下的人会记得你）、白骨堆里的储物袋、阴风、残阵、塌方、门人刁难、师兄喂招、藏经阁晒书、游方货郎（两成是假药）、扒手、白鹿饮泉、灵泉涨潮、狐妖进村、村童求艺，还有镇守之地的魔修来犯。双灵根碰上好事的多。闭关、没选地方直接过年时，只有凶险的地方才会出事。

### 名声

帮村民做事、行医、讲道、揭发、镇守、击退魔修攒下；推辞求助、不管魔修会掉。分四档：默默无闻、小有名气、名动一方、威震青冥。影响拜山和请人引荐的把握、宗主继任、有没有人慕名拜师、揭发温玄时有没有人信。

### 节奏

名角的大事有最早年份（`people.ts` 里的 `after`）：厉擎第 12 年、韩烈和柳如烟第 14 年、陆沉舟第 18 年、秦焰第 20 年、墨九第 22 年以后才会动手，之前只做准备。温玄、韩烈、柳如烟、墨九、花婆婆的年纪也调了，让他们活到故事里自己那一段。韩烈多了一条主线：趁厉擎下洞府时夺位；你人在赤霄门，他会先来探你口风（站他这边、去告诉门主、装没听见）。

延寿丹越吃越不灵（+30、+20、+10，之后没用）；心善的人再急也不为抢药杀人，只有阴狠的人拦路抢东西才下死手——打不过可以把东西交出去。后起之秀年头越久修为越高，各有说话的样子。

用 `npm run sim:qm` 量（300 局）：

| | 改之前 | 现在 |
| --- | --- | --- |
| 柳如烟、韩烈、陆沉舟、秦焰的中位死亡年 | 4、15、20、25 | 154、26、29、27 |
| 主线大事发生的年份 | 0～20 年 | 13～48 年，发生时 96～100% 的局你已经筑基 |
| 元婴以后的年份里有事找上门 | 2% | 21% |
| 化神率：随手玩（天/双/杂） | 48% / 4.5% / 0% | 46% / 28% / 20% |
| 化神率：精打细算（天/双/杂） | 72% / 40% / 6% | 93% / 78% / 83% |

### 修掉的毛病

- 盟友年年约你去空洞府取早被人拿走的玄冥剑（一局最多 91 次），也会约你去找已经死了的仇人
- 喜欢上你的人永远不表白
- 想要你东西的人只会要延寿丹，买和偷都没有下文，从此卡住
- 道侣、师父死了名分还在，死人身上的玄冥剑从此消失
- 你当上宗主后什么都不变，自身页还写「弟子」
- 修为没圆满点「闭关冲关」会白白耗掉这一年的主事

旧存档读进来时 `save.ts` 会补上新字段、修掉这些留下的坏数据。

### 新手引导和声音

第一年一步步带着走（去哪、主事、此地的人、过年），之后第一次遇到坊市、修为圆满、知道秘密、拿到遗书、交情变深、结丹时各提一句；看过的记在 `localStorage` 的 `qingming.tips.v1`，设置里能重看。

声音全是现场合成（`assets/ui/audio.ts`）：古琴似的拨弦弹五声音阶，地方不同音域不同；环境声随地方变——青岚宗山风和远钟、赤霄门风里的金铁声、云渡坊的人声和算盘、听泉谷的溪水、玄冥洞府低沉的回响和滴水、黑松林的夜风和鸮啼、柳溪村的鸟鸣；有人找上门、破境、知道秘密、过年、结局各有一声。顶栏的「声」字印可以关掉。

## 界面（第 3 阶段）

水墨古籍风：宣纸底、墨字、毛笔标题，人物头像是朱砂印章（交情越深印色越重：陌路淡墨、相识浓墨、相熟青绿、知己朱红、宿敌墨底红字）。手机竖屏优先，宽屏时居中；系统是深色时换成夜墨配色。还没有图片，美术在下一阶段。

| 地方 | 做什么 |
| --- | --- |
| 开局 | 起道号、选性别（灵根、出身由天定，进游戏先看身世）；有存档就能接着玩 |
| 顶栏 | 第几年、在哪；修为、气血、寿元、灵石；今年走到哪一步（动身 → 主事 → 打交道 → 过年）；谁正在想事 |
| 此地 | 年初是舆图和七个地方（谁在那里）；到了以后是主事、坊市、此地的人（各自今年的打算，哪些是自己拿的主意）、听见的话、过年和闭关 |
| 舆图 | 一张水墨小图：山、河、路，你在哪、每处几个人 |
| 人物 | 按交情排：身边的人、有交情的人、其他人、故人 |
| 人物抽屉 | 交情档位和离下一档还差多少、心里的你、对你的好感信任畏惧、来历性子打算、他记得的事、灵魂（认知层级和交情解锁的能力）、能对他做的事 |
| 对话 | 想说什么就说什么，回话边写边出；选项对话（寒暄、打听、问打算、请教、送礼、切磋、挑衅、拜师、道侣、引荐、相助、说出秘密）；对方的提议当场答应或婉拒 |
| 找上门 | 弹出来，来人开口的话（相识以上由 AI 来说）和选项、胜算 |
| 年终 | 这一年（闭关就是这几年）江湖上的事，和谁把你写进了「心里的你」 |
| 江湖 | 全部、大事、与我有关、听见的话 |
| 自身 | 资质、修为、寿元、行囊（能服的丹药）、你知道的秘密、小传 |
| 设置 | 由谁来演（离线 / DeepSeek / Claude）、密钥（只存在本机，页面上从不显示）、用量三档和交情对照表、花了多少钱 |
| 结局 | 坐化、陨落或化神；他们心里的你、小传 |

`assets/ui/view.ts` 全是纯函数（世界 + 界面状态 → HTML，AI 写的话一律转义）；`controller.ts` 管点击、表单、存档（`localStorage` 的 `qingming.save.v1`）、流式回话、AI 连接和记账；`map.ts` 是舆图；`style.css` 是样式。引擎宿主页自带的帧率角标在窄屏时压在底部菜单上，样式表把它收起来了。

## 角色的「心」

| 部分 | 在哪 | 做什么 |
| --- | --- | --- |
| 性格、价值 | `assets/game/data/people.ts` | 傲慢、谨慎、阴狠、痴情……五项价值：力量、财富、情义、忠诚、正义 |
| 长远目标 | `assets/game/mind/goals.ts` | 报仇、争宗主、寻师、求道侣、夺宝、求长生、拜入宗门，每种三四步，按年推进；秘密目标对外有一套说法 |

十二个人的目标和秘密是咬合的：温玄当年害了师兄云鹤、灭了墨家；沈清禾在找师父；墨九要报灭门之仇；陆沉舟想夺宗主之位，也是杀秦焰哥哥的人；苏小棠喜欢陆沉舟；白鹿暗恋沈清禾；厉擎和柳如烟都盯着洞府里的玄冥剑；韩烈想篡位；阿蛮想拜入宗门；花婆婆什么都知道一点。你知道的秘密可以告诉别人，会改变他们的打算。

## 接上天工引擎（第 2 阶段）

每个修士是引擎里一个挂着 `NpcBrain` 的实体，由引擎自带的 `npcPlugin` 驱动，按「认知 LOD」分三档：

| 档 | 谁 | 做什么 |
| --- | --- | --- |
| 聚光 | 正在和你说话的人 | 每帧感知 |
| 在场 | 和你在同一处的人 | 隔两秒感知一次 |
| 离场 | 别处的人、死了的人 | 不感知 |

AI 由谁来演、花多少心思，看下一节的「交情」。AI 能做的事全部作为引擎的 Intelligence Activity 提交，每帧 poll：

| 请求 | 什么时候 | AI 能决定什么 | 规则管什么 |
| --- | --- | --- | --- |
| 定打算 | 每年开头，你身边最多 3 个人 | 从规则给的选项里挑一件（包括为目标换一种做法：散布丑闻还是静等、买偷还是抢、分赃还是独吞），说一句心里话 | 选项本身；你已经到了地方，AI 不能让人凭空走掉 |
| 自由对话 | 你随便说一句 | 怎么回答、好感信任变多少、透露什么、顺势提出什么（指点、收徒、请你帮忙、切磋、卖丹药、结为道侣） | 每句好感 ±6、信任 ±4，每年谈话最多让好感 −12～+10；能透露、能提出的事要过门槛；秘密目标信不过你就只给说法、让 AI 骗你 |
| 选项对话 | 问近况、打听消息、问打算…… | 用这个人的口吻把规则的意思说出来 | 所有后果；不该说实话时，提示词里只有对外的说法 |
| 找上门 | 仇人、约你动手、表白、收徒、比斗 | 来人开口的那句话 | 选项和后果 |

AI 的回复不合规、出错、超时，一律退回规则的结果；换了一年或开了新局，还没回来的请求直接取消（不再花钱）。离线时走同一条 Activity 流程，用规则写好的回答。

## 角色灵魂：交情越深，越有灵性

AI 默认用 **DeepSeek V4.1 Flash**（模型 ID `deepseek-flash`）。不是每个人都一样聪明：和你打交道越多、爱恨越深的人，AI 越花心思去演他。

交情分 = 打交道攒下的（每说一句 +3、每次打交道 +4、找上门 +5、答复他的提议 +3，每年淡 15%）+ |好感|/4 + 信任/5 + 师徒、道侣 +25 + 他的目标冲着你（情、仇）+15。爱和恨都算，宿敌也会变聪明。交情分到 8、25、50 分别进下一档：

| | 陌路 | 相识 | 相熟 | 刻骨（知己 / 宿敌） |
| --- | --- | --- | --- | --- |
| 你和他自由对话 | 不思考，短上下文 | 不思考，多轮会话 | 浅想，带 16 条记忆 | 深想，带全部记忆和江湖传闻 |
| 选项对话、找上门时配台词 | 规则原文 | AI | AI | AI |
| 年初定打算 | 规则 | 在你身边时 AI | 在你身边时 AI（浅想） | 不在你身边也 AI（深想） |
| 你到了地方，他主动开口 | — | — | 会 | 会 |
| 他和身边人说话，你听得见 | — | — | 会 | 会 |
| 年底把这一年凝成一句「心里的你」 | — | — | 今年说过话才会 | 会 |

- 「心里的你」是长期记忆：记忆最多 30 条，旧的细节会被冲掉，这一句一直跟着他，写进以后所有提示词。
- 交情写在引擎 `NpcBrain.affordanceRef` 里（`qingming:0` … `qingming:3`）。交情一变，引擎的 npcPlugin 看到签名变化就重新 sync，灵魂「能做的事」随之变多（主动开口、旁听、年底回想、远处拿主意）。
- 自由对话和主动开口接着引擎的 `SessionRef` 往下聊：提供方按会话记住最近 12 轮问答，游戏只补上次说完之后发生的事。换了提供方、开新局就从头聊。
- 每次请求分两段：稳定的 system（世界、要求、人设、该不该瞒的目标和秘密）放前面命中 DeepSeek 的缓存；当下的处境、记忆、刚说的话放后面。
- 想多深：不思考时发 `thinking: {type: "disabled"}`；浅想、深想发 `reasoning_effort: low / high`。思考的内容只记账，不交给游戏。

### 用量和花费

设置里有三档用量：**省**（门槛 ×1.6，NPC 自己发起的请求每年最多 8 次）、**标准**（默认，24 次）、**尽兴**（门槛 ×0.6，64 次）。你自己开口说的话永远有 AI 回答，不算在里面。界面上实时显示这一局用了多少 token、缓存命中多少、约多少钱、花在谁身上。

用真的 DeepSeek 实测（`pnpm live`，标准档，按高峰价，闲时减半）：

| 玩法 | 请求 | 花费 | 中位耗时 |
| --- | --- | --- | --- |
| 到处走、和各种人说话，12 年 | 50 次 | 约 ¥0.13，每年约 ¥0.01 | 1.1~1.8 秒 |
| 一直跟着一个刻骨之人，6 年 | 43 次 | 约 ¥0.13，每年约 ¥0.02 | 1.4~2.2 秒 |

一局玩一百年，大约一两块钱。

### 密钥

密钥在游戏的「设置」里填（右上角齿轮，开局页也有入口），**只存在你自己浏览器的 localStorage 里**，只交给浏览器主线程的提供方，游戏世界那一侧、存档、构建产物里都没有。DeepSeek 接口允许浏览器直接调用（跨域已放行）。这适合自己玩；公开发布时应改成服务端代理，别把密钥发给玩家。

### 没用的引擎能力

引擎自带的 DeepSeek Harness 提供方（`@forgeax/engine/intelligence-dsh`）没有用：它要另装 DSH 的 JSON-RPC 运行时、每个 Activity 起一个进程、只能在 Node host 上跑，网页发布包里没有——对十几个修士频繁的短对话不合适。我们用的是同一套 Activity 接口上的 DeepSeek 流式提供方，换成 DSH 不需要改游戏代码。

| 文件 | 做什么 |
| --- | --- |
| `forge.json`、`assets/ids.ts` | 工程身份和两个根插件 |
| `assets/world.pack.ts` | 引擎侧根插件：注册 NpcBrain、npcPlugin、每帧 poll |
| `assets/world/session.ts`、`protocol.ts` | 世界会话：唯一持有存档；LOD 对齐、四类 Activity、校验和过期丢弃 |
| `assets/game/mind/bond.ts` | 交情：怎么攒、怎么淡、分几档，用量档 |
| `assets/game/ai/` | `decide.ts` 定打算，`talk.ts` 说话，`souls.ts` 主动开口、旁听、年底回想，`prompts.ts` 提示词的各块和按交情的深浅（`DEPTH`） |
| `assets/souls/` | 灵魂客户端、信封、AI 提供方（离线 / DeepSeek / Claude）、记账（`meter.ts`）、设置（`config.ts`）、Host 侧接线 |
| `assets/ui.pack.ts`、`assets/ui/` | 界面根插件和正式界面（见上面「界面」） |
| `scripts/live.ts` | 用真的 DeepSeek 自动玩几年，打印对话和账单 |

## 已知限制

- 引擎要画出第一帧才撤掉加载层、放开点击。没有显卡的机器（比如云端沙盒）要用引擎开发工具里的软件渲染参数启动 Chromium（`--enable-unsafe-webgpu --ignore-gpu-blocklist --enable-features=Vulkan --use-vulkan=swiftshader --use-angle=swiftshader`，再配一个虚拟显示器），否则软件 WebGPU 会丢设备，加载层一直不消失、点什么都没反应。用这组参数时大约 9 秒进游戏；有显卡的手机和电脑不受影响。
- 密钥存在浏览器里、由浏览器直接调用 DeepSeek，只适合自己玩。

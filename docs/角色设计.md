# 寒驿 · 角色设计

## 设计原则

1. **每个人都是一个机制，也是一个人。** 特质和本事决定他们能干什么（老秦打猎最好，胖叔掌勺最省粮，苏蔓干不了重活但能稳住人心）；性格、说话方式和秘密决定他们是谁。两者写在同一份数据里（`tiangong/assets/hanyi/data/characters.ts`）。
2. **信任是钥匙。** 每个人对你有一个信任值。信任来自夜谈、公道的决定、让大家吃饱穿暖；失去信任来自挨饿、偏袒、强迫。信任够了，他们才会说出心里的事。
3. **心事会改变局面。** 说出秘密不只是剧情：老秦的地窖能救一次粮荒，苏蔓的卫星电话和胖叔的电台能叫来救援，林晚的离开可能带回救援、也可能再也回不来。
4. **人和人之间也有账。** 一起干活、篝火边的闲聊、争吵时你站哪边，都会改变他们之间的关系。朋友让人心情好，不和的人凑在一起会吵架、会崩溃。
5. **在天工引擎里，每个人是一个 NPC 灵魂。** 天工版给每个角色一个 `NpcBrain` 实体（灵魂 ID `hanyi.<角色>`）。认知 LOD 决定他「多用心看世界」：正在和你说话的人是聚光，每帧感知；营地里的人是在场，每两秒感知一次；离开或去世的人是离场。每个灵魂还声明了自己「能做的事」：今天能接的活、能聊的话题、心事有没有说出口。
6. **他们会自己拿主意。** 每天早上，每个人按性子和营地的难处挑一件想干的活，并说一句理由；你照办，他会多信任你一点。夜里，心里有事的人会主动找你；围炉时，两个人之间也会聊起来。接上 AI 后，这些都由 AI 按人设来演。
7. **没有 AI 也完整。** 每个角色都有手写台词（按心情、信任、处境分档）。有 AI 时，同一份人设交给 Claude 即兴发挥，规则（每晚上限、秘密门槛）完全一样。

## 每个人的故事线

| 角色 | 解锁条件 | 事件 | 影响 |
| --- | --- | --- | --- |
| 老秦 | 夜谈时说出秘密（信任 ≥55），或信任 ≥70 | 护林站的地窖 | +8 食物、+2 药品、+3 柴火 |
| 老秦 × 阿杰 | 地窖之后，两人关系 ≥10 | 一张画像 | 老秦心结已解，心情大涨 |
| 阿杰 | 第 8 天后的清晨 | 山脊上的一格信号 | 给爸爸报平安（心结），或报告位置（救援提前，可能失败） |
| 林晚 | 第 9 天后，最晚第 13 天 | 林晚要走 | 劝留 / 让她走 / 让格桑护送；走了的话，成败要到结局才揭晓 |
| 林晚 × 小满 | 两人关系 ≥35 | 梦话 | 林晚有了牵挂，更容易被劝留 |
| 胖叔 | 找到客车后，说出秘密或信任 ≥65，或第 16 天 | 胖叔的心事 | 心结已解；当众说出会影响他和苏蔓、林晚的关系 |
| 胖叔 | 找到客车时选择拆回电台 | 修电台（营建） | 完工后救援提前 |
| 苏蔓 | 信任 <30 且大家心情差 | 苏蔓发难 | 据理力争 / 请她当副手 / 让她试试 |
| 苏蔓 | 第 10 天后；信任 ≥60 时她会主动交出 | 卫星电话 | 解锁「卫星电话供电」，完工后救援提前 |
| 小满 | 探路找到 | 发烧 | 用药 / 让懂医的人试试 / 硬扛 |
| 格桑 | 说出秘密或信任 ≥70 | 格桑的队伍 | 心结已解 |
| 吴铁 | 入营 4 天后 | 木雕 | 全营地心情提升 |
| 吴铁 | 说出秘密、信任 ≥75，或和小满关系 ≥40 | 吴铁开口 | 心结已解 |

救援最早第 18 天才能上山（路要抢通，暴风雪里直升机也飞不了），所以提前救援是奖励，不是捷径。

## 通用事件

- **争吵**：关系很差的两个人（暴躁、挨饿会让情况更糟）。站队、找人调解或各打五十大板，都有成功率。
- **崩溃**：心情低于 12。陪他、找他的朋友陪他，或让他歇两天。
- **偷吃**：心情差、信任低、又挨饿的人会在夜里偷粮。守夜的人能抓到。
- **出走**：连续两天心情崩溃的人可能在夜里离开。守夜的人能拦住。
- **狼群**：第 4 天后，夜里可能来。守夜的人够强能赶跑，瞭望台和围栏能减损。
- **过命的交情 / 手艺**：关系好的人会成为挚友，本事好的人会教关系好的人。
- **暴风雪、过路猎户、死亡与葬礼**。

## 结局

撑到第 30 天（或提前的救援到来）时结算。每个人的结局取决于：是否活着、是否离开、心结是否解开、最后的心情和对你的信任。共四档：平安下山（心结已解）/ 平安下山 / 下落不明 / 长眠于此。

## 加一个新角色

在 `tiangong/assets/hanyi/data/characters.ts` 里加一项（特质、本事、性格、说话方式、背景、秘密、台词、结局），在 `CHAR_ORDER` 里排上位置。如果不是开局就在的人，在 `tiangong/assets/hanyi/systems/work.ts` 的探路表里加一个相遇结果，在 `tiangong/assets/hanyi/data/events.ts` 里写相遇和故事线事件。AI 对话会自动用上新人设。

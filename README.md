# 寒驿

一款以角色为核心的生存经营小游戏。

> 寒潮来得毫无征兆。客车在山道上抛锚，五个陌生人躲进了半山腰一座废弃的驿站。广播里最后一条消息说：大雪封山，道路至少一个月才能打通。你成了那个拿主意的人。

- **生存**：柴火保暖，食物果腹，药品治病。天越来越冷，附近的猎物越打越少。
- **经营**：每天给每个人派活（砍柴、狩猎、搜寻、探路、营建、掌勺、照料、安抚、守夜、休息），决定口粮和取暖的松紧，选择先建什么。
- **角色**：八个人，每人有自己的性格特质、本事、心情、对你的信任、彼此之间的关系，和一件藏在心里的事。夜里围着火和他们说话，信任够了，他们会开口——而那往往会改变整局的走向。

## 美术

像素画风，人物、图标、背景是一个画风。八个人都是手绘的 48×48 像素半身像，各有标志：老秦的雷锋帽和驿站钥匙、林晚的低马尾和护士服、阿杰耳朵上的铅笔、胖叔脖子上的白毛巾、苏蔓的金丝眼镜、小满怀里的布兔子、格桑缀着绿松石的辫子和雪镜、吴铁的工作帽和橘色反光背心。每人三种表情跟着心情换，还会隔几秒眨一下眼。「众人」页最上面是一幅会动的驿站剖面图：左边林子里有人砍柴、打猎，屋里有人掌勺、照料病人、躺在上下铺歇着，右边门口有人守夜，有人背着包去翻雪里的车，有人顺着小路去探路。柴火堆随柴火多少变高变矮，房梁上挂的肉随食物多少变化，封窗、火塘、医务角、熏肉架、瞭望台、电台修好了都会出现在画里。傍晚天色泛暖，夜里大家回到火边坐成一圈，守夜的提着灯站在门外。点画里的人，白天是给他派活，夜里是和他说话。下面是一张张人物卡，事件和夜谈是全屏的画加人物和对话框。天上会按天气下像素雪，暴风雪时又密又斜；一天的三段之间有过场大字卡，存粮增减会从数字旁飘出来。

声音全是现场合成的：风雪声随天气变大变小，夜里有柴火噼啪，配乐是像古琴一样的拨弦，弹五声音阶。

背景是宋、元、明、清的雪景和梅花古画，缩成了像素画，和人物一个画风：标题和结局是袁耀的雪山客栈，白天的日头是刘松年的雪中草堂，夜里围炉是马远的月下观梅，每个事件和每个人也各配一幅。白天用暖色，夜里把同一类画染成冷蓝。画作来自大都会艺术博物馆开放获取（公有领域，CC0），图标来自 game-icons.net（CC BY 3.0）。完整清单见 [CREDITS.md](CREDITS.md)。

改人物长相：改 `scripts/pixel/people.mjs`，用 `node scripts/pixel/preview.mjs 预览.png` 看效果；改图标：改 `scripts/pixel/icons.mjs`。换画：改 `art/paintings/` 里的图，再运行 `python3 scripts/pixelate.py`（需要 Pillow）。改完运行 `npm run art`，再运行 `npm run build`。

## 两个版本

| 版本 | 在哪 | 怎么打开 |
| --- | --- | --- |
| 独立网页版 | 仓库根目录 | 浏览器直接打开 `dist/index.html`；在 claude.ai 里打开时夜谈由 Claude 扮演 |
| 天工引擎版 | [`tiangong/`](tiangong/README.md) | 跑在天工引擎（ForgeaX Engine 0.4.8）上，每个角色是一个引擎 NPC 灵魂，AI 可以接 DeepSeek 等接口 |

两个版本共用同一套玩法代码（`tiangong/assets/hanyi/`），玩起来一样。

## 怎么玩

进度自动存在浏览器里。

一天分三段：

1. **白天**：点画里的人或人物卡下面的按钮派活，点人像看底细。派完点「结束今天」；要是有人会挨饿、受冻、累倒，会先提醒你。
2. **傍晚**：看收成，处理当天发生的事（相遇、争吵、意外……每个选择都有后果）。
3. **夜里**：围炉夜话。点火边的人和他说话，每人每晚最多聊四句，聊天会改变信任和心情。在 claude.ai 里打开时，夜谈由 Claude 即兴扮演每个角色，可以说任何话；在别处打开则用手写台词。

撑到第三十天，路就通了。也有人能让救援提前到来——前提是你得先走进他们心里。

### 人心

每个人有一条三四章的「心路」：先是某个清早或夜里露出一点心事（老秦站在后山的岔路口，林晚的手机只剩百分之四的电，阿杰速写本上画满了同一个背影……），再是夜里信任够了说出口，然后是一件改变他的事，最后解开心结。有的人的故事线有不止一种走向：林晚留下来，也可以替女儿过一个迟到的生日；阿杰把短信发给了救援热线，也还能把那张画画完。

人和人之间也有自己的故事：胖叔和苏蔓先结下旧账，过几天才会有一块腊肉；老秦和格桑在同一座山上失去过人；吴铁会给小满缝好豆豆的耳朵。底部菜单的「人心」页有一张关系图（绿线要好、红线不和，越粗越深），列着他们之间发生过的事，和每个人的心路走到了哪一章（下一章会给提示）。有人的故事往前走了，菜单上会亮红点。

他们会记得你：夜里聊过什么、说出口的心事、事件里你替谁说了话。点开人像能看到「他记得的事」；之后聊天时，他们会提起前几天的事（「「旧账」那天的事，我还没想通。」）。接上 AI 时，这些记忆会写进提示词，AI 还能自己记下一件这次对话里要记住的事。

第一次玩时，第一天会一步步带着你；之后第一次遇到傍晚、夜里、能开工的时候各提一句（日志页可以重看）。日头上的每个数字、人物卡上的三条状态都能点开看说明。左上角可以关掉声音。

## 代码结构

```
tiangong/                天工引擎工程（详见 tiangong/README.md）
  assets/hanyi/          玩法本体，两个版本共用
    core/                状态类型、可存档随机数、插件宿主、读写状态的工具
    data/                数据包：角色（人格+台词+结局）、规则（特质/岗位/工程）、事件（events.ts、events-story.ts）、各人的心路（stories.ts）
    systems/             玩法插件：干活、口粮取暖、身心、人际、营建、天气、剧情调度、结局
    ai/                  围炉夜话：手写台词、提示词、回复校验；自己拿主意（intent.ts）；记忆（memory.ts）
    game.ts              把插件按顺序装进引擎，对外提供操作
  assets/ui/             界面渲染（纯函数）、样式、驿站场景（scene.ts）、声音合成（audio.ts）、画面反馈（fx.ts），两个版本共用
  assets/camp.pack.ts    天工版：游戏世界根插件（NpcBrain、Intelligence）
  assets/ui.pack.ts      天工版：界面根插件
  assets/souls/          天工版：灵魂客户端、AI 提供方
src/
  main.ts                独立网页版入口：点击处理、存档、接上 Claude
scripts/
  build.mjs              把独立网页版打包成单个 HTML
  art.mjs                美术：人物像素像、像素化的背景、图标 → tiangong/assets/ui/art.css、icons.ts
  pixel/                 像素画：画布和描边（draw.mjs）、八个人的半身像（people.mjs）、驿站场景的小人和道具（scene.mjs）、图标（icons.mjs）、预览图（preview.mjs）
  pixelate.py            把古画缩成像素画背景
  sim.ts                 无头模拟：用不同策略连玩几百局，检查平衡
```

游戏状态是纯 JSON，所有玩法都是挂在「白天结算 / 夜里结算」上的插件，界面只负责显示。改角色、改数值、加事件都只动 `tiangong/assets/hanyi/data/`。

```bash
npm install
npm run build   # 生成独立网页版 dist/index.html
npm run check   # TypeScript 类型检查
npm run sim     # 平衡模拟（默认 300 局）
```

当前平衡（`npm run sim`，300 局）：一个看得见所有数值、按规则精打细算的策略，97% 的局没有团灭，95% 的人活着下山；随机派活几乎全灭；什么都不干撑不过第九天。

## 天工引擎版

天工引擎就是 ForgeaX Engine（造化工坊）。在 `tiangong/` 里：

```bash
cd tiangong
pnpm install
npx -y @forgeax/game init      # 绑定工程，并给各个 AI 工具装上引擎技能
pnpm test                      # 行为测试
pnpm exec forgeax project build --json
pnpm exec forgeax project preview --json
```

AI 角色用的是引擎自带的两层能力：

- **NPC（`@forgeax/engine/npc`）**：每个角色一个 `NpcBrain` 实体，带灵魂 ID 和认知 LOD（聚光 / 在场 / 离场）。引擎的 `npcPlugin` 每帧扫描它们，我们的灵魂客户端按 LOD 决定多久重新感知一次世界。
- **Intelligence（`@forgeax/engine/intelligence`）**：每句夜谈是一个 Activity，边生成边显示；AI 提供方（离线台词、DeepSeek、其他 OpenAI 兼容接口、Claude）在浏览器主线程运行，密钥只在那一侧，经引擎的端口桥接给游戏世界。

完整说明、架构图和已知限制见 [tiangong/README.md](tiangong/README.md)；开发中发现的引擎问题记在 [tiangong/docs/feedback.md](tiangong/docs/feedback.md)。

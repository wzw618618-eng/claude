# 开宗立派（试玩版）

在荒山开宗：收徒、用人、定方略、御强敌。弟子们各有性格和心愿，由 AI 按性格自己过日子；你只看大概，做决策。

在线玩：<https://wzw618618-eng.github.io/claude/kaizong/>（电脑、手机都能玩；手机横过来是左右两栏，竖着是上下翻）

## 玩法

- **开局。** 只定一件大事：山门立在哪（灵脉宝地、深山、坊市旁）。出身、宗门传承由天定，开宗后揭晓。
- **殿堂一座座建。** 开局只有灵植园和巡山队（丹师多一座丹房）。迎客堂、丹房、外事堂、器阁、执法堂、传功殿要花灵石、满足条件（丹房要先有灵植园，执法堂要弟子满 8 人……），建一两季才落成；扩建也要时间。工匠有限，同时只能建一处，中品宗门以后两处。先建什么，是开头几年最要紧的取舍。
- **开春。** 每年开春看一眼去年回顾，挑一件今年的**大计**（新收几个弟子、出一位筑基、名望涨到多少、办几件任务……），办成了有赏，没办成弟子们觉得宗主说话不算数；再定方略、点一格传承。
- **宗主亲为。** 宗主每季自己做一件事：闭关（一路修到元婴，到了元婴宗门底气大不一样）、亲传一个弟子（炼气的当场长一层）、坐镇山门（压怨气、护山）、下山游历（带回好苗子、灵药，或者听到风声）、开炉炼丹、登门拜山。
- **宗门任务。** 任务栏上挂着几件差事：剿妖、护送、采药、探遗府、调解纷争、追剿魔修、寻访良才、代人炼丹炼器、擂台。挑一到三个弟子组队出去，打打杀杀的看战力，炼丹调解的看本事，界面上写着把握。越凶险赏得越多，也越可能有人回不来。
- **宗门品阶。** 草创 → 下品 → 中品 → 上品宗门 → 一方圣地。攒够弟子、筑基、名望、殿堂、灵脉就晋一阶，各方来贺；任务格、召见名额、每季供奉跟着涨。只升不降。
- **一回合一季。** 安排好人手、处理完待裁决的事，点"过季"。弟子们各自拿主意：修炼、偷懒、交朋友、表白、使绊子、挑战上级、叛逃……季报告诉你发生了什么。
- **用人。** 干得好不好 = 才干 × 他愿不愿意 × 心情。讨厌的活会积怨。修为高的人屈居人下会不服；修为低的人坐高位，下面的人也不服。宗门大比排定的座次一年内大家都认。
- **招人。** 印象不一定准；测灵根花灵石，考才干花候选人的耐心，查来历要等一季。有人撒谎，有人是敌宗的奸细，天才会被别家抢。记名弟子试用一年再定。
- **心愿联动。** 你的决定碰巧成全了谁的心愿（比如为抢灵脉打仗，正好杀了他的仇人），他会记在你头上。
- **方略和传承。** 每年定一个主攻方向，在传承树上点一格（有一条魔道路线）。
- **天下。** 赤霄宗霸道，玄水阁精明，太一门是正道之首。别家每年都在收人、修炼，后几年说不定有宗主冲上元婴，前几年站稳了也不能高枕无忧。送礼、结盟、挑衅、宣战；被打上门时部署派谁、怎么打、要不要亲自出手。灵脉丢光后再输一场，山门就没了。
- **召见。** 每季能当面见三个人。问近况能听出他不服谁、讨厌什么差事、有没有别家来挖他；安抚消怨气，勉励提心情，敲打让他这一季不敢偷懒使坏（心气高的会记恨）。离线也能召见，后果都按规则算；接上 AI 后由 AI 照这个意思用他的口吻说，还能随便聊。
- **冲关。** 弟子修为圆满会来求你准他闭关；被"压一压"的人每年开春再来求。也能在人物卡上直接下令，筑基丹、灵石能提高成算。
- **人心隔肚皮。** 偷东西、使绊子、给敌宗送信不会写进季报，奸细嘴上说的心愿也是一套说辞。库房对不上账、有人日子莫名不好过，就是有人在搞鬼；执法堂越得力越容易抓到人。
- **标记 ★。** 你关心的弟子事情排在季报最前面，接了 AI 时每季都由 AI 来想。点任何一个小人都能看他的经历。
- **十年一局。** 到年头给宗门下评语（一州魁首、名门大派……），列出每个入过山门的人的去向，和开山以来的宗门志。

第一年季报顶上有一步步的指引；顶栏小字是上一季家底的增减；灵石只够发两三季月例时会提醒。花灵石、丹药的选项不够就灰掉，写明缺多少。

## AI

设置里选 DeepSeek，填自己的密钥（只存在本机浏览器里，由浏览器直接调用 DeepSeek，不经过别的服务器）。档位：省钱（每季 3 人）、正常（8 人 + 敌宗宗主）、阔气（16 人 + 敌宗宗主）。不接 AI 也能玩，用规则和写好的台词。

AI 只决定"做什么、心里怎么想"：从代码列出的合法做法里挑一件，用他的口吻说一句话；新心愿也由 AI 写。成不成、数值怎么变都由规则算。

## 开发

```
cd kaizong
npm install
npm test            # vitest：修炼、服不服、心愿联动、招募、过季、AI 校验、召见、冲关、奸细藏不藏得住、结局、任务、宗主亲为、品阶、大计
NEW=0 npm run sim -- 300 smart   # 机器人不用任务、宗主亲为、大计时的平衡
npm run check       # 类型检查
npm run sim -- 300 smart    # 平衡模拟（smart / random）
npm run build       # 生成 index.html（GitHub Pages 直接用）
```

| 目录 | 内容 |
| --- | --- |
| `src/game/` | 纯逻辑：修炼（`cult.ts`）、岗位与服不服（`sect.ts`）、弟子能做的事（`choices.ts`、`resolve.ts`）、心愿（`wishes.ts`）、待裁决（`decisions.ts`）、招募（`recruit.ts`）、事件奇遇（`events.ts`）、敌宗（`rivals.ts`）、宗门战（`war.ts`）、过季（`season.ts`）、召见（`talk.ts`）、宗主亲为（`master.ts`）、宗门任务（`missions.ts`）、品阶和大计（`goals.ts`）、营造（`build.ts`）、结局（`ending.ts`）、旧存档补字段（`save.ts`） |
| `src/ai/` | DeepSeek 流式客户端、提示词、问 AI 和校验 |
| `src/ui/` | 界面、占位头像、宗门地图、样式 |
| `scripts/` | 构建、平衡模拟 |

平衡（300 局）：会玩的机器人十年存活约 79%、宗门战胜率约 55%、平均晋到下品宗门、四分之一的局宗主修到元婴；乱玩的约 42%。器阁建得晚，打仗明显吃亏。

画面目前是占位图（SVG 小人和山）。动漫风立绘由 ChatGPT 按美术需求文档画，画好后替换。

# 开宗立派（试玩版）

在荒山开宗：收徒、用人、定方略、御强敌。时间自己往前走，弟子们各有性格和心愿，由 AI 按性格自己过日子；你看着山上的人来来往往，在要紧的时候拍板。

在线玩：<https://wzw618618-eng.github.io/claude/kaizong/>（电脑、手机都能玩，一律横屏；手机竖着拿会自动转过来）

## 玩法

- **时间自己走。** 没有"过季"按钮了。一季九十天，顶上能暂停、正常（一天约 0.4 秒，一季半分多钟）、两倍、四倍；空格键暂停，1/2/3 调快慢。弟子们按天干活、修炼、领月例；每人一季里挑一天自己拿主意，头上冒的气泡就是他心里的话。
- **事情要花时间。** 盖殿堂一到三个月，山上能看见脚手架一点点长高；派人下山办差事一两个月才回来，山门边挂着他们的小牌子和倒计时；弟子冲关要进洞闭关十五天，洞口放光，出关时金光冲天或者受伤；宗主闭关、亲传一季一轮，游历、拜山两个月。
- **有事来找你。** 想冲关、出意外、奸细被抓……右上角冒出一封信，大事默认停下来等你拍板（设置里可改成每件都停或者都不停），拖过期限按"不管"办。宣战或被宣战后二十天打上门，顶上倒计时。每年开春停一下定大计、方略、传承。
- **横屏。** 中间整块是山门，四周是顶栏、左边菜单、右边抽屉。手机竖着拿时整个游戏自动转 90 度，横过手机就是正的（开了方向锁也一样）；安卓点"开宗"时会顺手进全屏锁横屏。
- **开局。** 只定一件大事：山门立在哪（灵脉宝地、深山、坊市旁）。出身、宗门传承由天定，开宗后揭晓。第一年左上角一步步带你：收徒、派差事、盖殿堂、派任务、召见。
- **殿堂一座座建。** 开局只有灵植园和巡山队（丹师多一座丹房）。其余要花灵石、满足条件，工匠有限，同时只能建一处（中品宗门以后两处）。点山上的空地就能去建。
- **宗主亲为。** 闭关（一路修到元婴）、亲传一个弟子、坐镇山门、下山游历、开炉炼丹、登门拜山。做满一轮出结果再接着做；中途换别的，这一轮就白做了。
- **宗门任务。** 任务栏每季换新：剿妖、护送、采药、探遗府、调解纷争、追剿魔修……挑一到三个弟子组队出去，界面上写着把握和要走几天。
- **品阶和大计。** 草创 → 下品 → 中品 → 上品宗门 → 一方圣地。每年开春挑一件大计，左上角显示进度。
- **用人。** 干得好不好 = 才干 × 他愿不愿意 × 心情。讨厌的活会积怨。修为高的人屈居人下会不服；修为低的人坐高位，下面的人也不服。小人头上的字：闲（没差事）、怨、圆（修为圆满待冲关）、伤、修、勤、懒、斗……
- **招人。** 上山来的人在山门口等着，等不及就走。测灵根花灵石，考才干花耐心，查来历要一个多月。有人撒谎，有人是敌宗的奸细，天才会被别家抢。
- **心愿联动、方略和传承、天下、召见、人心隔肚皮、标记 ★、十年一局** 都和以前一样，只是不再按回合，而是按日子发生。

## 参考的开源项目

改成实时之前在 GitHub 上找了同类项目：

| 项目 | 参考了什么 |
| --- | --- |
| [A Dark Room](https://github.com/doublespeakgames/adarkroom)（MPL-2.0，8k 星） | 实时经营的节奏：工种按固定间隔出产、事件按随机间隔冒出来、时间一直在走。这里按天走、每半个月飘一次产出、事件排在季内随机的日子 |
| [修仙世界模拟器 cultivation-world-simulator](https://github.com/4thfever/cultivation-world-simulator)（2k 星） | AI 驱动的 NPC 各自过日子、玩家当"天道"看着并插手；长动作（修炼、突破）跨好几个月，做完自动结算 |
| [我的放置仙途 vue-idle-xiuxian](https://github.com/setube/vue-idle-xiuxian)（MIT） | 修为条、进度条一直在涨的放置节奏（这里切到别的页面就停，不算离线收益） |
| [MainLoop.js](https://github.com/IceCreamYou/MainLoop.js)（MIT） | **直接用了**：固定步长的游戏时钟，切到后台回来不会一下跳好几季 |
| [ZzFX](https://github.com/KilledByAPixel/ZzFX)（MIT） | **直接用了**：音效全靠它现场合成（钱币、敲锤、钟声、冲关成功的上行音、打仗的鼓） |

A Dark Room 是 MPL 许可，只学了做法，没有拷代码。两个 MIT 库的许可证见 `THIRD_PARTY.md`。

## AI

设置里选 DeepSeek，填自己的密钥（只存在本机浏览器里，由浏览器直接调用 DeepSeek，不经过别的服务器）。档位：省钱（每季 3 人）、正常（8 人 + 敌宗宗主）、阔气（16 人 + 敌宗宗主）。不接 AI 也能玩，用规则和写好的台词。

每季开头在后台问 AI，时间不用停；答案回来之前就到日子的人按规则自己拿主意。

AI 只决定"做什么、心里怎么想"：从代码列出的合法做法里挑一件，用他的口吻说一句话；新心愿也由 AI 写。成不成、数值怎么变都由规则算。

## 开发

```
cd kaizong
npm install
npm test            # vitest：按天走的时钟、修炼、服不服、心愿联动、招募、AI 校验、召见、冲关、奸细藏不藏得住、结局、任务、宗主亲为、品阶、大计
NEW=0 npm run sim -- 300 smart   # 机器人不用任务、宗主亲为、大计时的平衡
npm run check       # 类型检查
npm run sim -- 300 smart    # 平衡模拟（smart / random）
npm run build       # 生成 index.html（GitHub Pages 直接用）
```

| 目录 | 内容 |
| --- | --- |
| `src/game/` | 纯逻辑：时钟（`season.ts`：`dayTick` 过一天、季初排日程、季末结算）、修炼（`cult.ts`）、岗位与服不服（`sect.ts`）、弟子能做的事（`choices.ts`、`resolve.ts`）、心愿（`wishes.ts`）、待裁决和闭关（`decisions.ts`）、招募（`recruit.ts`）、事件奇遇（`events.ts`）、敌宗（`rivals.ts`）、宗门战（`war.ts`）、召见（`talk.ts`）、宗主亲为（`master.ts`）、宗门任务（`missions.ts`）、品阶和大计（`goals.ts`）、营造（`build.ts`）、结局（`ending.ts`）、旧存档补字段（`save.ts`）、给画面的提示（`fx.ts`） |
| `src/ai/` | DeepSeek 流式客户端、提示词、问 AI 和校验 |
| `src/ui/` | 山门场景（`scene.ts` 人和动画、`art.ts` 手画的 SVG 山和殿堂）、顶栏和四角（`hud.ts`）、抽屉和弹窗（`views.ts`）、横屏（`orient.ts`）、音效（`sfx.ts`）、样式 |
| `scripts/` | 构建、平衡模拟 |

平衡（150 局）：会玩的机器人十年存活约 88%、宗门战胜率约 62%；乱玩的约 51%、宗门战几乎全输。

画面是手写的 SVG（山、殿堂、头像），没有外部图片。动漫风立绘画好后可以替换头像和背景。

# 决策记录

文档没写到的细节，按“可解与规则正确 > 体验 > 画面；更简单、改动更小；引擎已有的直接用”取舍。每行：日期 · 决定 · 理由。

- 2026-11-07 · 新游戏放在仓库的 `zongmen/` 目录，不删除寒驿、青冥录 · 用户说不用管之前的游戏；不动旧代码，避免误删别人的东西。
- 2026-11-07 · 第 0 阶段的两个阻断（运行时模型、比赛规则）等用户答复期间，先做 M1、M2 的纯逻辑部分 · 这部分不依赖任何平台结论，换引擎、换模型都能整体带走。
- 2026-11-07 · 7 个地点都可勘察（需求里有一处写“6 个”） · 地点表列了 7 个，流程里写的是“点击 7 个地点之一”。
- 2026-11-07 · 地点、特征在代码里用英文 id，显示用中文名 · id 稳定，文案可以随便润色。
- 2026-11-07 · 数据文件打包成 `src/data/bundle.gen.ts`（`npm run data`），测试检查它是否最新 · 逻辑层在 Node、测试和引擎打包里都只需要 import 一个 TS 模块，不依赖各自的 JSON/Markdown 加载方式。
- 2026-11-07 · 增加数据文件 `data/template_lines.json`（模板应答的口吻、语气和意图关键词），提示词拆成 `system_disciple.md`、`rules.md`、`turn.md`、`epilogue.md` · 需求要求台词和提示词都放数据文件。
- 2026-11-07 · 角色加 `aliases`（大师兄、小鱼……），秘密加第三人称的 `review` · 编造检查要认出别称；真相复盘要用第三人称。
- 2026-11-07 · 有秘密者的说法一律是“在居所”，具体做什么取他自己在居所的日常（看书、打坐、对账……） · 需求写“通常是在房里睡觉”；用各自的日常更像人话。
- 2026-11-07 · 非居所的目击者给“那时那里只有我（和某某）”；同处一地的人另外各给一条 presence 证词 · 矛盾规则里只有 presence 能打破“在别处”的说法，exclusive 不隐含 presence，分开写才符合“当且仅当”的四条规则。
- 2026-11-07 · 居所里的目击者互相作证用“起夜时听见隔壁鼾声” · 居所是一排单间，看不见彼此。
- 2026-11-07 · 伪证模式 C 的环境物证：丹房门上长老戌时贴的封条、膳堂门上长老的铜锁 · 戌时早于任何案发时辰，说得通“那时没人进得去”。
- 2026-11-07 · 陪绑者是目击者时，把另一名目击者调到他那里，优先用后者自己在该地点的日常说法，没有就用通用说法 · 保证不在场证明有人证实，说法仍自然。
- 2026-11-07 · 打字问话：先回答，再按模型判定的语气加减压力；出示证据：先加压力，再回答 · 语气要等模型输出才知道；证据的判定代码事先就知道。所以坦白/失言最快在“下一次回答”触发，和需求一致。
- 2026-11-07 · 压力到 100 时，若还有没演完的坦白或失言，先让他演完再拒答 · 否则关键线索可能永远拿不到。
- 2026-11-07 · 已坦白的人再被出示矛盾，判“已坦白过”，压力不变 · 谎话已经收回，不该再算矛盾。
- 2026-11-07 · 屏蔽词命中：消耗 1 次问话，不调用模型，回兜底台词 · 仍是一次问话；不给模型看不雅内容。
- 2026-11-07 · 单局调用超过 40 次后改用模板应答，而不只是回避台词 · 模板应答也是兜底，但仍按知识卡回答，保证这一局还能破案。
- 2026-11-07 · 模型报错或超时：本轮重试 1 次，仍失败就切到模板应答，本局后面都用模板，并提示“夜深了，弟子们有些困倦……” · 需求第 7 节；避免每轮都等 15 秒超时。
- 2026-11-07 · 编造检查只在“同一句里同时出现他人名字（含别称）和地点名或时辰名”时触发；“那里只有我”这类事实视为覆盖所有人 · 只聊为人不算编造；“没见到某某”本身就是 exclusive 事实的内容。
- 2026-11-07 · 坦白校验额外要求回话含秘密关键词；内奸没到失言时说出失言关键词算泄底 · confessed/slipped 只是标注，要防止标了却没说、没标却说了。
- 2026-11-07 · 弟子初始压力为 0 · 需求没规定；从 0 开始，出示两次矛盾正好到坦白线 60。
- 2026-11-07 · 开发和评测用 `deepseek-flash`（DeepSeek-V4.1-Flash），对话时关闭思考 · 用户提供了 DeepSeek Key；关闭思考后 p90 延迟约 1.4 秒，评测全部达标，单局约 ¥0.03。
- 2026-11-07 · token 估算按中文 0.75、其余 0.35 · 用 deepseek-flash 实测校准，实际约为估算的 95%；超过 2500 时从最早的历史轮次开始丢。
- 2026-11-07 · 对话历史只存“本轮事件 + 回话 JSON”，不重复每轮的状态块 · 满 8 轮历史时单次输入仍在 2500 token 以内。
- 2026-11-07 · 出戏词表去掉“指令”“设定” · 这两个是普通词，“什么设定不设定的”只是戏里的困惑；需求点名的“提示词、知识卡、JSON”等保留。
- 2026-11-07 · 认罪检测跳过反问和否定（“是不是我偷的？”“不是我偷的”） · 真实模型常这样反驳，原先会误判。
- 2026-11-07 · 回应出示的证据时，提到证据里的人不算编造；否定句（“没注意大师兄去哪”）也不算 · 实测中出现的误判。
- 2026-11-07 · 截断回话时，若失言或坦白的关键词在 80 字之后，放宽到 120 字、截在那句句末 · 否则说漏的话会被截掉。
- 2026-11-07 · 问到见闻、点名问某人、问行踪时，代码算出“本轮必须说出的公开事实”写进指示，并校验至少说了一条；已坦白的人主动交代 · 实测中老实目击者被问“见到了谁”却答“没见到”，关键破绽拿不到。需求“老实人被问到就会说”。
- 2026-11-07 · 秘密增加 `leak_keywords`：坦白前说出就算泄底（不收物证文字里本来就有的词） · 实测中有秘密的人被出示证据后自己把秘密讲了出来。
- 2026-11-07 · 失言说出了却忘了标 slipped 时，以回话内容为准自动更正 · 标注只是辅助，玩家看到的是回话。
- 2026-11-07 · 评测增加“如实作证”一项，“守住秘密”一半用例改成刚被出示证据 · 覆盖实测发现的两个问题。
- 2026-11-07 · 评测的“格式”只看 JSON 和字段是否合法 · 需求写的是“JSON 第一次就合法”。
- 2026-11-07 · 引擎用官方插件 `@forgeax/game` 0.4.2 对应的 ForgeaX 0.4.8，不追最新的 0.4.19 · 插件（造化插件）绑定的就是 0.4.8；仓库里之前的游戏也在 0.4.8 上跑通过。
- 2026-11-07 · `zongmen/` 直接作为引擎工程根目录，逻辑层从 `src/` 移到 `assets/game/` · 引擎规定 `assets/` 是唯一的内容根目录；逻辑层仍不引用任何引擎 API，Node 里照常测试。
- 2026-11-07 · 体素用顶点颜色着色，每个模型只有“普通”和“发光”两个材质槽 · 引擎的标准材质支持顶点颜色变体，比每种颜色一个材质简单得多；发光体素（灯笼、炉火）单独用自发光材质。
- 2026-11-07 · 游戏逻辑和模型调用放在浏览器前端一侧，引擎只负责画面：界面通过 `GameHost.port` 下“镜头、站位、动作”指令 · 界面、存档、网络请求都在前端；引擎可能跑在 Worker 里，不碰 DOM。
- 2026-11-07 · 地点标签和头顶情绪图标用 HTML 浮层，按与引擎相同的镜头公式投影到屏幕 · 比在 3D 里做文字和点选简单，触控区域也好保证 44 像素。
- 2026-11-07 · 情绪图标用一个字的色块（静、慌、怒、惧、悲、安），不用 emoji · emoji 在不同设备上的字体和样式不一致。
- 2026-11-07 · 头像取角色体素模型的正面投影画成像素图 · 和场景里的模型完全一致，不需要另画。
- 2026-11-07 · 地图机位按屏幕宽高比自动拉远，保证 7 个地点的标签都在画面里 · 横屏和竖屏手机的可视范围差很多。
- 2026-11-07 · 镜头过渡在足够接近时直接吸附到目标 · 指数平滑永远到不了终点，标签会一直微动，点不稳。
- 2026-11-07 · 本机代理只在本机页面且地址带 `?proxy=1` 时自动连接；默认用模板应答 · 连不上的请求会在控制台报错，引擎的截图验收把控制台错误当失败；发布版也不该去探测本机端口。

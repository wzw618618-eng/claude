# 进度

## 2026-11-07

### 完成了什么

- **第 0 阶段核实**：结论在 [docs/RESEARCH.md](docs/RESEARCH.md)。引擎（ForgeaX 0.4.19，Apache-2.0）和插件（`@forgeax/game`，官方支持 Claude Code）都找到了；**运行时模型服务和比赛规则两项查不到，需要用户提供信息**。
- **M1 案件与规则（已达标，tag `m1`）**
  - 带种子的随机数、事实结构与矛盾自动推导、案件生成器、求解器、规则引擎、状态机。
  - 连续 1000 个种子 100% 通过，最多重试 1 次，单案平均 0.1 毫秒。
  - 命令行：`npm run cli -- case <种子>` 打印案件全貌和每名弟子的知识卡；`npm run cli -- check` 批量校验。
  - 单元测试覆盖随机数、生成器与求解器、四种矛盾条件的正反例、压力增减、坦白与失言触发、压力 100 拒答、四档评级。
- **M2 AI 弟子（逻辑完成，真实模型部分待定）**
  - 提示词全部在 `data/prompts/`，人设和知识卡在前、本轮状态在最后一条消息。
  - 输出校验流水线（格式 → 权限 → 泄底 → 编造 → 失言），失败重生成 1 次，仍失败用兜底（回避台词 / 坦白模板 / 失言模板）。
  - 模板应答模式：只用它就能完整打通一局，破案和失败两种结局都有自动化回放测试（200 个种子全部能只凭线索簿推出内奸）。
  - 模型报错或超时自动切到模板应答；单局调用硬上限 40 次。
  - 命令行文字版：`npm run cli -- play [种子]`。
  - AI 评测脚本 `npm run eval`（63 条用例）；目前只用模板应答干跑过，报告在 `docs/eval/`。
